# Obtaining the datasets

No medical image or original dataset archive is included.

1. Obtain VQA-RAD directly from [OSF](https://doi.org/10.17605/OSF.IO/89KPS).
2. Obtain SLAKE from the authors' distribution or `BoKelvin/SLAKE` on Hugging Face.
3. Review `DATA_LICENSES.md` before use or redistribution.
4. Do not publish the upstream RadGrounder split JSON files unless their repository licence is verified.

Derived eligibility manifests and split-validation records used for the publication audit are located under `reproducibility/manifests/`.
